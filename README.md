## Philosophy

I’ve never viewed software development as memorizing stacks or collecting buzzwords.

My work has always centered around:

- learning systems quickly
- solving difficult operational problems
- improving usability
- modernizing aging workflows
- helping people work more effectively
- balancing technical depth with human-centered design

I’m especially drawn to front-end and UX work because I enjoy seeing ideas come alive — but I also thrive on the broader puzzle-solving aspects of software development: troubleshooting, performance bottlenecks, architecture, workflow design, and technical adaptation.
