## Profile

I’m a tool-agnostic application developer with a strong front-end and UX focus. I like messy problems: aging systems, confusing workflows, performance bottlenecks, unfamiliar tools, and projects where the path forward is not immediately obvious.

My career has spanned government, enterprise consulting, publishing, internal systems, technical writing, teaching, and application architecture. Across that range, the pattern has stayed consistent: learn the system quickly, understand the humans using it, find the friction, and make the tool clearer, faster, and more useful.

I’m especially drawn to front-end work because I enjoy seeing ideas become usable. But I’m not looking to be boxed into a single layer of the stack. I’m at my best when UX, architecture, troubleshooting, and practical problem-solving overlap.

## Selected Systems & Projects

### Workload Distribution Tool (WDT)

**Contra Costa County EHSD**

Took over a critical workload distribution project after the original vendor was removed midway through development. Led the remaining development and support for a .NET / SQL Server application used by roughly 1,000 eligibility and social work staff.

The system distributed work based on staff availability, skill sets, bilingual capabilities, vacation schedules, and other operational constraints. It also integrated with CalWIN data, including read-only Oracle-backed data sources that were painfully slow when I inherited them.

Reworked the data access and query approach enough to reduce some of the worst-running calls from minutes, and in some cases closer to an hour, down to a few seconds.

WDT stayed in production for several years with very few true application defects. Most support calls ultimately traced back to user error, network issues, or upstream database/data problems. The system did what internal tools are supposed to do: it solved the problem and kept working.

### STARS.NEXT / Knowledge Management Modernization

**Contra Costa County**

Contributing front-end UX work for STARS.NEXT, a new knowledge management system currently in concept/prototype development. The long-term goal is to turn STARS into an AI-driven application that helps county employees find information, documents, and operational knowledge more easily.

My focus is the front-end experience: modernizing the interface, improving usability, and helping define standards we can reuse on future projects. The work is also serving as a test case for newer county development patterns, including Azure-hosted .NET MVC applications with stronger CSS and JavaScript support.

This is the kind of project I enjoy: new territory, real users, a messy information problem, and enough room to help shape how the system should feel.

### CFS Wraparound System

**Contra Costa County EHSD**

Architected and developed an internal application used to track services and payments connected to foster care and child welfare programs.

The direct user group was small, but the system supported staff managing information tied to thousands of children receiving county services. I handled the full development lifecycle, including requirements, database design, application architecture, front-end design, development, testing, and support.

This was one of the first major county systems I built after joining EHSD, and it set the tone for a lot of my later work: understand the workflow, build something usable, and make sure the people doing the work can actually trust the tool.

### Trust Fund Management System

**Contra Costa County EHSD**

Designed and developed an internal financial tracking system for managing trust fund allocations for children under county care.

The county holds the funds in a shared Wells Fargo account, while the application tracks each child’s individual entitlement, balance, interest, and related activity. The goal was to give staff a clearer, more reliable way to manage funds that were not separated at the bank-account level.

Like a lot of useful internal systems, it was less about flashy features and more about getting the logic right, making the data understandable, and reducing the chance of mistakes.
