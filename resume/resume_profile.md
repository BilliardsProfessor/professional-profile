## Profile

I’m a tool-agnostic application developer with a strong front-end and UX focus. I like messy problems: aging systems, confusing workflows, slow queries, unfamiliar platforms, and projects where the path forward is not obvious yet.

My career has moved through government, consulting, publishing, internal systems, technical writing, teaching, and application architecture. The pattern has stayed pretty consistent: learn the system, understand the people using it, find the friction, and make the tool clearer, faster, and easier to trust.

I enjoy front-end work because I like seeing ideas become usable. But I do not want to be boxed into one layer of the stack. I’m at my best when UX, architecture, troubleshooting, and practical problem-solving overlap.

## Selected Work

### Contra Costa County EHSD

**Information Systems Programmer / Analyst IV**  
_November 2012 – Present_  
Administrative Department, Application Development

Highest-level role in the ISPA classification, focused on application development, front-end modernization, internal systems, workflow tools, and long-term support for county operational applications. Started as a Robert Half contractor in March 2012, continued as a county temporary employee in November 2012, and became a full-time county employee in October 2013.

#### Workload Distribution Tool (WDT)

Took over a critical workload distribution project after the original vendor was removed midway through development. Led the remaining development and support for a .NET / SQL Server application used by roughly 1,000 eligibility and social work staff.

The system distributed work based on staff availability, skill sets, bilingual capabilities, vacation schedules, and other operational constraints. It also integrated with CalWIN data, including read-only Oracle-backed data sources that were painfully slow when I inherited them.

Reworked the data access and query approach enough to reduce some of the worst-running calls from minutes, and in some cases closer to an hour, down to a few seconds. WDT stayed in production for several years with very few true application defects. The system did what internal tools are supposed to do: it solved the problem and kept working.

#### STARS.NEXT / Knowledge Management Modernization

Contributing front-end UX work for STARS.NEXT, a new knowledge management system currently in concept/prototype development. The long-term goal is to turn STARS into an AI-driven application that helps county employees find information, documents, and operational knowledge more easily.

My focus is the front-end experience: modernizing the interface, improving usability, and helping define standards we can reuse on future projects. The work is also serving as a test case for newer county development patterns, including Azure-hosted .NET MVC applications with stronger CSS and JavaScript support.

#### CFS Wraparound System

Architected and developed an internal application used to track services and payments connected to foster care and child welfare programs. The direct user group was small, but the system supported staff managing information tied to thousands of children receiving county services.

Handled the full development lifecycle, including requirements, database design, application architecture, front-end design, development, testing, and support.

#### Trust Fund Management System

Designed and developed an internal financial tracking system for managing trust fund allocations for children under county care.

The county holds the funds in a shared Wells Fargo account, while the application tracks each child’s individual entitlement, balance, interest, and related activity. The system gave staff a clearer, more reliable way to manage funds that were not separated at the bank-account level.
